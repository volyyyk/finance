Полностью автономное веб-приложение для учёта денег: работает офлайн, устанавливается
на телефон как приложение, считает прогноз на 10 лет вперёд и ничего не отправляет
на сторонние серверы без вашего ведома.

## ✨ Возможности

- 💵 **Продукты** — вклады, кредиты, кредитные карты, инвестиции и расходы: суммы, ставки, графики платежей, даты окончания
- 📈 **Инвестиции** — акции, облигации, фонды, драгметаллы; группировка по видам и бумагам, купоны и амортизации облигаций, котировки с МОЕХ (ISS API), доходность фондов
- 🧮 **Прогноз** — симуляция баланса на 1 мес / 1 год / 5 / 10 лет с учётом всех событий: купонов, платежей, пополнений и погашений
- 🎯 **Цель** — прогресс-бар «капитал → цель» и оценка срока по вашему чистому темпу накоплений
- 🏦 **Кешбэк** — банки и категории за месяц, топ-3 категории, постоянные словари банков
- 🔔 **Уведомления** — предстоящие списания по кредиткам и напоминание о сверке расходов; на Android работают через service worker
- 🌗 **Тёмная тема** — переключение в один тап, включая нативные контролы (чекбоксы, календари)
- 📴 **Офлайн-first** — Service Worker кэширует всё, приложение полностью работает без сети
- ☁️ **Синхронизация** — необязательная облачная копия с защитой от затирания локальных правок

## 🚀 Запуск

1. Откройте сайт по **HTTPS** (или локальный сервер на `localhost` — `file://` не поддерживает PWA).
2. В настройках нажмите **«Загрузить демо»** — приложение заполнится примерами всех разделов.
3. Добавьте свои продукты; на телефоне — «Установить приложение» из меню браузера.
4. После обновления сайта один раз нажмите **«Обновить»** в настройках, чтобы подтянуть новый кэш.

## ✅ Тесты

```bash
npm test          # или: node --test tests/*.test.cjs
```

89 тестов в трёх наборах: `bonds` (11), `cashback` (9) и `full` (69) —
облигации, симулятор, статистика, события, кешбэк, MOEX API, цели, дашборд,
редактор активов, Android-уведомления, seed-данные и целостность сборки.
Вариативные серии используют детерминированный PRNG (mulberry32).

## 🔒 Приватность

Все данные хранятся в браузере (localStorage). Облачная синхронизация — опциональна
и отключена по умолчанию; внешние запросы — только котировки МОЕХ.
