Полностью автономное веб-приложение для учёта денег: работает офлайн, устанавливается
на телефон как приложение, считает прогноз на 10 лет вперёд и ничего не отправляет
на сторонние серверы без вашего ведома.

## ✨ Возможности

- 💵 **Продукты** — вклады, дебетовые карты, кредиты, кредитные карты, инвестиции, квартиры и расходы: суммы, ставки, графики платежей, даты окончания; одинаковые типы сворачиваются в раскрывающийся список, закрытые продукты уходят в серый архив в конце
- 🏢 **Квартира** — учёт стоимости имущества (рост по умолчанию 8%/год), сдача в аренду (₽/мес — в доход) и ремонт (по умолчанию 2% стоимости в год — в расход), плашки доходности аренды
- 📈 **Инвестиции** — акции, облигации, фонды, драгметаллы; группировка по видам и бумагам (счётчик наименований в шапке вида), купоны и амортизации облигаций, котировки с МОЕХ (ISS API: поиск по ISIN, тикеру и названию, включая БПИФ; драгметаллы — цена за грамм), доходность фондов
- 🧮 **Прогноз** — симуляция баланса на 1 мес / 1 год / 5 / 10 лет двумя сценариями: событие-за-событием и «без учёта событий» (вклады не закрываются, доходность сохраняется до горизонта); продукты «вне бюджета» исключены из баланса, но доход/расход продолжают влиять на статистику; снятие можно пометить «платёж по долгу» — тогда платёж по кредитке уменьшает долг, а не списывается из баланса второй раз
- 📆 **События** — ближайшие события постранично (6 на страницу, до 4 страниц), включая погашения облигаций; тап по событию открывает карточку продукта; календарь кликабельный — тап по дате с событиями показывает их на панели, пустые даты не реагируют
- 📊 **Графики** — интерактивные точки на каждой отметке оси: тап на телефоне или наведение на ПК показывает сумму баланса на эту дату
- 🎯 **Цель** — имя и сумма, прогресс-бар «капитал → цель» и оценка срока по вашему чистому темпу накоплений
- 🏦 **Кешбэк** — банки и категории за месяц в два столбца (банк — под названием категории, блоки не вылезают за экран; проценты подкатегорий всегда видны и подсвечены по размеру, длинные подписи «банк · подкатегория» плавно прокручиваются по кругу), топ-3 категории, подсветка размера кешбэка цветной полосой и процентом — по проценту основной категории (до 3% красная, 3–5% жёлтая, от 5% зелёная), постоянные словари банков
- 📤 **Экспорт** — таблица Excel (.xls) со всеми продуктами и итогами: общий баланс (активы), общий долг и чистый капитал
- 🔔 **Уведомления** — предстоящие списания по кредиткам, напоминание о сверке расходов и напоминание в начале месяца добавить категории кешбэка за новый месяц; на Android работают через service worker
- 🌗 **Тёмная тема** — переключение в один тап, включая нативные контролы (чекбоксы, календари)
- 📴 **Офлайн-first** — Service Worker кэширует всё, приложение полностью работает без сети
- ☁️ **Синхронизация** — необязательная облачная копия с защитой от затирания локальных правок

## 🚀 Запуск

1. Откройте сайт по **HTTPS** (или локальный сервер на `localhost` — `file://` не поддерживает PWA).
2. В настройках нажмите **«Загрузить демо»** — приложение заполнится примерами всех разделов.
3. Добавьте свои продукты; на телефоне — «Установить приложение» из меню браузера.
4. После обновления сайта один раз нажмите **«Обновить»** в настройках, чтобы подтянуть новый кэш.

## ✅ Тесты

```bash
npm test          # или: node --test tests/*.test.cjs
```

118 тестов в трёх наборах: `bonds` (11), `cashback` (11) и `full` (96) —
облигации, симулятор, статистика, события, пагинация событий, погашение
облигаций, кликабельный календарь, прогноз «без событий», квартира,
продукты «вне бюджета», имя цели, группировка типов и архив продуктов,
кешбэк с подсветкой, MOEX API, дашборд, редактор, Android-уведомления,
seed-данные и целостность сборки.
Вариативные серии используют детерминированный PRNG (mulberry32).

## 🔒 Приватность

Все данные хранятся в браузере (localStorage). Облачная синхронизация — опциональна
и отключена по умолчанию; внешние запросы — только котировки МОЕХ.
