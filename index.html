Установка на телефон · Подготовка автономного режима…

Android: откройте этот сайт в Chrome по HTTPS. Нажмите «Установить приложение» или выберите в меню браузера «Установить приложение» / «Добавить на главный экран».

iPhone и iPad: откройте сайт в Safari → «Поделиться» → «На экран Домой» → «Добавить».

Дождитесь статуса «Готово к работе без интернета», затем запускайте приложение с его значка. Учёт, редактор, графики, импорт и экспорт работают без сети. Поиск бумаг, свежие котировки MOEX и ставка ЦБ требуют интернета. Сохранённые цены могут устареть.

APK для установки не нужен. Сайт не создаёт APK-файлы. Ошибку «Файл повреждён» у стороннего APK нельзя определить без самого файла и сведений о его сборке.

Данные сохраняются в облаке с доступом из этого браузера; локальная копия позволяет работать без интернета. Очистка cookies лишает доступа к облачной копии. Для переноса на другое устройство используйте экспорт и импорт.
